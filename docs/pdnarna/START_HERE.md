# PDNA/RNA behavior update

This ZIP updates the previously delivered **pdnarna-3 integration** to **pdnarna-4**.
It adds inherited, resource-paid local sensing/movement and shows actual colony
positions, growth, division, lineage and allele diversity in Roblox. It contains
source changes and a patched copy of your supplied place. No GitHub operation or
prebuilt Windows executable is involved.

Everything installs into your existing project:
`E:\cultivated_intelligence\CultivatedIntelligenceNative\CultivatedIntelligenceNative`.
The extracted ZIP is only an installer; it is not a second running project.

## Install and resume your current world

Stop Studio Play and stop the old native process with Ctrl+C so it saves. Extract
this ZIP. In PowerShell, start in the extracted folder containing the installer.
Run the preflight first and continue only if it reports success:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\Install-PDNARNA.ps1 -Root 'E:\cultivated_intelligence\CultivatedIntelligenceNative\CultivatedIntelligenceNative' -Check
```

The execution-policy command applies only to this terminal and resolves the
"running scripts is disabled" error. It does not change your project location.
Then install, build, and resume:

```powershell
.\Install-PDNARNA.ps1 -Root 'E:\cultivated_intelligence\CultivatedIntelligenceNative\CultivatedIntelligenceNative'
Set-Location 'E:\cultivated_intelligence\CultivatedIntelligenceNative\CultivatedIntelligenceNative'
.\scripts\Build.ps1
.\scripts\Start-PDNARNA.ps1 -Runtime runtime/pdnarna -Seed 42
```

Run each command after the preceding one succeeds. **Omit `-NewWorld` when resuming.**
Use your existing runtime path and its original seed if they differ. The launcher
upgrades a model-3 checkpoint automatically and first retains its exact bytes in
`runtime/pdnarna/physiology.checkpoint.json.pdnarna-3.backup` (or a numbered backup
if a different backup already exists). Existing material, genetics, lineage and
random state are preserved. New sensing/motor machinery begins at zero and must
be synthesized, so a resumed colony does not immediately acquire full speed.

The installer preflights all files, refuses conflicting edits, backs up sources,
accepts LF/CRLF and safely handles repeat installation. It does not install trial
checkpoints or change saved worlds or connection credentials. If it reports a
conflict, retain that file and reconcile the difference before installation.

## Update Roblox too

From another PowerShell terminal in the same main project directory:

```powershell
rojo serve planet/pdnarna.project.json --port 47126
```

Open your current place, connect the Studio Rojo plugin, and sync before Play.
This scoped project updates the four reviewed scripts and the server connection
configuration generated by the launcher. It preserves other scripts and assets.
Keep HTTP requests and the existing sky/water permissions enabled. This is a local
Studio connection; Python is not a runtime dependency.

Alternatively open `foruastra_smileyface_PDNARNA_Behavior.rbxl` from this ZIP. It is
a patched copy of the original uploaded place, not a copy of any subsequent local
Studio edits. Its verification file identifies exactly four changed script sources;
all other chunks are byte-identical to that original. Still sync the current native
connection configuration through Rojo.

## What to observe

- Mobile producers explore and respond to local light; decomposers respond to local
  food and oxygen. Speed and sensing depend on paid protein and available energy.
- Attached producers remain on the substrate. Growth, division and offspring
  dispersal provide their activity.
- Models follow persistent C++ colony IDs, with smooth position updates. Body size
  follows structural growth; a division splits actual material and adds a daughter.
- Color differences encode inherited alleles. Select a colony to inspect its parent,
  generation, genome, DNA/RNA/protein, action, movement cost and sensing/motor traits.
- Roblox displays a bounded sample: up to 24 colonies, six patches and 192 parts.
  The global census is much larger; every birth need not be visible nearby.

The reference active speed is 1.2 studs per real second at full reference motor
protein and sufficient energy. Actual speeds vary. These are magnified research
markers and scenario rates, not a claim about species-specific physical speed.

Check the new display in Studio: movement near light/food, colony inspection,
growth/births, mat grounding, identity across patches, leaving/re-entering interest,
feed stoppage and save/resume. Automated Luau checks do not replace visual/FPS
validation on your machine. See `VALIDATION.md` for the measured results.

## Roll back

Stop both processes. Use `Restore-PDNARNA.ps1 -Root PROJECT -Backup BACKUP` from this
ZIP with the source-backup path printed by installation, then rebuild. For an
already upgraded runtime, also restore the original model-3 checkpoint backup:
retain the model-4 checkpoint separately before copying the model-3 backup back to
`physiology.checkpoint.json`. That returns the simulation to the pre-upgrade tick;
newer model-4 progress cannot be loaded by the old executable. Resync the old Roblox
scripts too. The source rollback intentionally does not overwrite simulation saves.

The optional Python installer uses `Install-PDNARNA.py --root PROJECT --check`,
then `--root PROJECT`, and its `--rollback BACKUP` option. Python is needed only for
this alternative installer and optional developer validation scripts.

## Reproduce validation

From the main project after a Release build:

```powershell
python tests/validate_pdnarna.py --executable build/native/Release/validate_physiology.exe --output results/behavior-reproduction
python tests/assess_pdnarna.py --results results/behavior-reproduction --output results/behavior-reproduction/assessment.json
```

Use an empty output directory. For a single-configuration generator, omit `Release/`.
The original finite-horizon ecology gates are retained; this update does not reuse
the previous model's ecology results as evidence for the changed movement model.
